# Code of Conduct

## Our standard

We want `react-helmet-pro` to be a respectful, collaborative, and safe project for maintainers, contributors, and users.

Examples of expected behavior:

- being respectful in disagreements
- giving constructive, actionable feedback
- assuming good intent while staying honest about problems
- focusing discussion on the code, docs, and user impact

Examples of unacceptable behavior:

- harassment, discrimination, or personal attacks
- trolling, intimidation, or deliberately hostile language
- publishing private information without permission
- disruptive behavior that makes participation unsafe or unnecessarily difficult

## Scope

This applies to project spaces such as issues, pull requests, discussions, releases, and other public or private interactions related to the repository.

## Reporting

If you experience or witness unacceptable behavior, please open a private security advisory or contact the maintainers through GitHub so the report can be handled discreetly.

Project maintainers may remove, edit, or reject comments, commits, code, issues, or pull requests that do not align with this code of conduct.
